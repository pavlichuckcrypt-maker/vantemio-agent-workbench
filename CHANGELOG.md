# Changelog

## 0.5.0 — 2026-10-26

Preserve already complete native trusted context without inserting a duplicate task block. Add explicit host-estimate admission while keeping unknown hard token bounds labelled unknown; strict upper bounds remain the default. Add one-pass Chat/Responses SSE usage observation, exact owned command-prefix normalization, and qualified local Source aliases for read retention. Protect original provider bytes, terminal failures, task/host bindings and physical path containment. Expand the suite to 115 cases and the offline installed-package consumer. Native enrollment, durable ledgers, permissions and Source authority remain host responsibilities; no cache percentage or uninterrupted provider service is promised.

## 0.4.0 — 2026-10-26

Add a common prepare/dispatch-boundary/observe adapter, qualified serializer extension points and explicit original provider usage normalization. Preserve native model/output parameters and reasoning/tool identities; reject changed task/Source/documents, lifecycle uncertainty and mismatched original outcomes. Cache UNKNOWN and final-snapshot coverage stay explicit; historical cache never grants automatic input credit. Harden provider failure accounting by native session. **Migration:** `providerFailureState` now requires `sessionID` alongside provider/model. Installed-package consumer and four usage protocols are covered; live chat settings are unchanged by this release.

## 0.3.1 — 2026-10-26

Recognize the exact native `UnknownError` / `The operation timed out.` provider deadline in the existing bounded transient recovery policy. Bare tool timeouts, owner aborts, quota/key/model failures and unsettled tools remain excluded. Regression verifies exact error classification; native acceptance included a new successful assistant/read and subsequent ordinary step after safe shared backend loading, without replaying tools or changing the Goal/model.

## 0.3.0 — 2026-10-25

Add portable Source/result capture and projection for existing Chat Completions text tool messages. Preserve exact original invocation/receipt and Source versions; changed/unresolved evidence remains historical without tool replay. Add 21 regression cases and RU/EN host integration contracts. No new storage authority, reader, watcher or live chat settings.

## 0.2.0 — 2026-10-25

Add an exported bound system-transform hook around the per-request document reader. It preserves the full Goal/project context and existing system entries, checks actor/session/Goal/revision/input before and after reads, and rejects Stop or inconsistent/oversized context without dispatching. Add a host-adapter recipe and offline model/tool caller regressions. No live agent settings or tasks are changed.

## 0.1.1 — 2026-10-25

Read required task documents for each system transform, avoiding stale initialization snapshots. Filesystem regression checks cover updates, missing/unreadable documents and separate workspaces.

## 0.1.0 — 2026-10-25

Initial public policy/configuration reference. Seven reusable modules, credential-free profiles, ten pinned upstream skills, offline tests and RU/EN documentation. Private runtime adapters and product code excluded.
