# Changelog

## 0.6.0 — 2026-10-28

- Preserve authenticated active working Source across historical read-budget demotions, with changed-input/hash negatives.
- Add portable original-receipt reconciliation with before/after task and Stop checks; preserve UNKNOWN and distinguish completed failures from success.
- Add byte/count bounded proof caching, same-byte Source observation deduplication, explicit incomplete read previews and matching maintenance-hold qualification.
- Add host-exclusive continuation CAS/receipt helpers that preserve newer owner state and native provider/model/reasoning choice.
- Add regression negatives, offline installed consumers and RU/EN integration contracts. No host deployment settings, private adapters or product histories are included.

## 0.5.3 — product naming and operations

- Present the project as Vantemio Agent Workbench, a reliability toolkit for autonomous coding-agent development. Keep the technical package name and exports compatible.
- Add RU/EN ownership, safe maintenance, exact-input reconciliation and normal-consumer acceptance guidance. Runtime code remains version 0.5.3.


## 0.5.3

- Recognize interrupted empty native tool inputs as failed operations that were never dispatched; running, partial, provider-executed or unknown-effect tools remain protected.
- Permit an explicitly configured necessary fresh-input ceiling up to50,000; smaller policies remain valid. Cache evidence and physical context are separate.
- Add regression negatives and RU/EN native recovery guidance.


## 0.5.2 — 2026-10-26

Preserve original error/call/input/time, reject replaceAll, partial-output and unrelated mutation errors, and retain host identity/Stop/UNKNOWN/no-replay guards. Add public regressions, an installed-package ambiguous-edit consumer, and updated RU/EN integration contracts.

## 0.5.1 — 2026-10-26

Classify the exact terminal native edit rejection for identical old/new strings as a known failure before execution. Preserve the original error and input/call/time hashes; keep arbitrary mutation failures, running tools and UNKNOWN outcomes blocked. Add19 public regressions and an offline installed-package consumer. Native host acceptance resumed the same stopped task without replaying its rejected edit.

## 0.5.0 — 2026-10-26

Preserve already complete native trusted context without inserting a duplicate task block. Add explicit host-estimate admission while keeping unknown hard token bounds labelled unknown; strict upper bounds remain the default. Add one-pass Chat/Responses SSE usage observation, exact owned command-prefix normalization, and qualified local Source aliases for read retention. Protect original provider bytes, terminal failures, task/host bindings and physical path containment. Expand the suite to 115 cases and the offline installed-package consumer. Native enrollment, durable ledgers, permissions and Source authority remain host responsibilities; no cache percentage or uninterrupted provider service is promised.

## 0.4.0 — 2026-10-26

Add a common prepare/dispatch-boundary/observe adapter, qualified serializer extension points and explicit original provider usage normalization. Preserve native model/output parameters and reasoning/tool identities; reject changed task/Source/documents, lifecycle uncertainty and mismatched original outcomes. Cache UNKNOWN and final-snapshot coverage stay explicit; historical cache never grants automatic input credit. Harden provider failure accounting by native session. **Migration:** `providerFailureState` now requires `sessionID` alongside provider/model. Installed-package consumer and four usage protocols are covered; live chat settings are unchanged by this release.

## 0.3.1 — 2026-10-26

Bare tool timeouts, owner aborts, quota/key/model failures and unsettled tools remain excluded. Regression verifies exact error classification; native acceptance included a new successful assistant/read and subsequent ordinary step after safe shared backend loading, without replaying tools or changing the Goal/model.

It preserves the full Goal/project context and existing system entries, checks actor/session/Goal/revision/input before and after reads, and rejects Stop or inconsistent/oversized context without dispatching. Add a host-adapter recipe and offline model/tool caller regressions. No live agent settings or tasks are changed.
