# Vantemio Agentic Backend — русский

Открытый набор переносимых политик и примеров настроек backend для автономных coding-агентов. Здесь опубликованы общие механизмы нашей вахты: продолжение задач, сохранение оригинальных исходов, ограниченное восстановление, подключение плагинов, темп запросов и контроль свежего/кэшированного контекста.

Это **не полный сервер OpenCode и не приватное ядро Studio**. Транспорты, авторизация, хранилище, проекция контекста, сериализация конкретных API и исполнение инструментов остаются адаптерами интегратора. Нельзя скопировать пример профиля в OpenCode и считать интеграцию готовой.

## Проверка

Node.js >=22; npm-зависимостей и install-скриптов нет:

```sh
npm test
npm run check:release
```

## Работа

1. Сохранить полную цель, её ревизию и текущую задачу.
2. Найти существующий код/потребителя; удерживать только необходимые диапазоны с SHA.
3. Воспроизвести дефект, сделать минимальное изменение и проверить реальное поведение.
4. Сохранять Stop, live tools, исходные IDs и UNKNOWN. Не повторять неопределённые операции.
5. Продолжать следующий незавершённый этап. Не подменять разработку перечитыванием и отчётами.

Целевой свежий контекст — до15 тысяч токенов, необходимый максимум35 тысяч; подтверждённый кэш — до70 тысяч, общий предел80 тысяч. Это примеры бюджетов, а не лимиты конкретного провайдера. Нет обещания80–90% кэша: нужны фактические usage и стабильный необходимый префикс. Не добавлять текст ради кэша.

Десять upstream-навыков закреплены в `config/skills.lock.json`; загружать только нужный. В upstream-примерах нет разрешения удалять существующий код ради TDD, создавать платных субагентов, обходить ограничения или повторять неизменные проверки. Действующие требования владельца и границы проекта имеют приоритет.

Подробности и границы интеграции — INTEGRATION.md. Обновления проходят тесты и проверку публичного diff; автоматического экспорта рабочих каталогов нет.
