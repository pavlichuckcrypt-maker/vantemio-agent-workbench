# Native recovery / Нативное восстановление

OpenCode1.19.3 creates pending tool inputs with `input:{}` and `raw:""`. The tool-call transition replaces the pending state before execution; cleanup retains its raw marker and assigns equal start/end times. See [official processor source](https://github.com/anomalyco/opencode/blob/v1.19.3/packages/opencode/src/session/processor.ts), ensureToolCall, tool-call and cleanup.

`knownNativeNoEffectFailure` accepts only the precise interrupted empty-input shape for native tools requiring arguments. It returns a FAIL/no-dispatch observation. It never marks a write successful, edits native history, resumes a chat or replays a command. Missing raw, nonempty arguments, different times, execution metadata, provider execution or output remain UNKNOWN. Use authenticated native observations only. Owner Stop, permissions, current Goal/input and dispatch-ledger guards belong to the host adapter. Verify actual recovery through a subsequent normal generation and real tool result in the same chat.

OpenCode1.19.3 создаёт pending input с `input:{}` и `raw:""`. До исполнения переход tool-call заменяет это состояние. Очистка прерванного pending input сохраняет raw и ставит одинаковые start/end. Функция принимает только эту строгую форму у инструментов с обязательными аргументами. Результат — FAIL без отправки операции. История не меняется, команда не повторяется, успешная запись не заявляется. Непустые аргументы, исполнение, output, другие timestamps и неизвестные эффекты остаются защищёнными. Используйте только аутентифицированные native данные. Stop/Goal/input/permissions/ledger проверяет host adapter. Приёмка — следующий обычный ответ и результат инструмента того же чата.

## Context and cache / Контекст и кэш

The validator permits a chosen fresh-input maximum up to50,000 tokens and total up to80,000; existing smaller policies remain valid. Hosts must also enforce the selected model's physical context/output limits. Cache hits require original provider usage. Local archives are not provider cache hits. Avoid restoring evicted optional Source on every request. New task/Goal/hash or newly required Source must invalidate reused derivative projections. Private host adapters, product Source and native history are excluded from this public library.

Валидатор допускает выбранный максимум новых токенов до50тыс. и суммарный до80тыс.; меньшие значения остаются валидными. Host также соблюдает физический контекст и output модели. Кэш подтверждается original provider usage; локальный архив не является cache hit. Не возвращайте убранный необязательный Source в каждом запросе. Новый task/Goal/hash или вновь нужный Source отменяют производную проекцию. Приватные host adapters, продуктовый Source и native история исключены из публичной библиотеки.
